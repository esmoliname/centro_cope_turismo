# Centro Cope

Sitio web de aterrizaje (landing page) para **Centro Cope**, un destino turistico y recreativo integral: bar restaurante, cancha de futbol 5, salon de eventos y futura cabana de hospedaje, rodeados de naturaleza.

## Estructura del proyecto

`
centro_cope_turismo/
+-- index.html          # Pagina principal (HTML5 semantico, SEO y accesibilidad)
+-- css/
|   +-- styles.css      # Design system (Apple HIG + Material Design 3 tokens)
+-- js/
|   +-- main.js         # Navbar, FAQ accordion, galeria lightbox, reveal on scroll
+-- assets/
|   +-- images/         # Fotografias del complejo (.jpeg)
+-- .gitignore
+-- README.md
`

## Tecnologias

- HTML5, CSS3 (variables, animaciones, glassmorphism)
- Tailwind CSS (CDN)
- JavaScript vanilla (ES6+)
- Google Fonts (Plus Jakarta Sans, Inter)
